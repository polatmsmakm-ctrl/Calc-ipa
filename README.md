# حاسبة (الخزنة المخفية)

تطبيق يظهر كحاسبة عادية 100%. الخزنة تنفتح فقط إذا كتبت الرمز السري واضغطت `=`.

## الاستخدام
1. أول تشغيل: اكتب رمزك (٤ أرقام أو أكثر) واضغط **مطوّلاً** على `=` لحفظه.
2. لفتح الخزنة: اكتب الرمز واضغط `=`.
3. بصمة/وجه (اختياري): الإعدادات داخل الخزنة، ثم اضغط مطوّلاً على شاشة الأرقام في الحاسبة.
4. القفل تلقائي لما تطلع من التطبيق.

## البناء
ارفع المحتوى كامل لريبو GitHub (فرع main) وشغّل Actions، وبعدها نزّل `Calc-ipa` وثبّته بـ Sideloadly.

## ملاحظات
- كل شيء مخزّن محلياً ومشفّر (AES-256-GCM). مفتاح التشفير في Keychain الجهاز.
- لا تغيّر `PRODUCT_BUNDLE_IDENTIFIER` في project.yml بعد ما تبدأ تخزّن، لأن الملفات مربوطة بالتطبيق.
- اسم التطبيق على الشاشة من `CFBundleDisplayName` في project.yml.
